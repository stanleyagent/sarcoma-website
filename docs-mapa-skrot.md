# SARCOMA – propozycja mapy nowej strony sarcoma.pl

## Cel
Nowa architektura informacji w miejsce obecnego serwisu (2020). Propozycja łączy: wymagania funkcjonalne, treści ze starej strony (~150 stron + 29 historii) oraz dobre praktyki z serwisów pacjenckich.

## Zasady
1. Dwa główne wejścia: „Szukam pomocy” (wg sytuacji) i „Nowotwory” (wg choroby).
2. Hub nowotworu ze ścieżką leczenia (objawy → diagnostyka → leczenie → życie po leczeniu).
3. Maks. 3 poziomy nawigacji.
4. Infolinia i wsparcie zawsze widoczne.
5. Jeden hub „Wspieram” (darowizna, 1,5%, Onkobieg itd.).

## Menu główne (skrót)
- Szukam pomocy — ścieżki sytuacyjne + infolinia, konsultacje, wsparcie, gdzie się leczyć
- Nowotwory — huby: Mięsaki / Czerniak / Raki skóry (+ typy i ścieżka leczenia)
- Wiedza i materiały — poradniki, ABC, wideo, historie, publikacje
- Projekty — Onkobieg, profilaktyka, #FuraZdrowia itd.
- O nas — misja, zespół, dokumenty, partnerzy, kontakt
- Aktualności
- [Przycisk] Wspieram

## Plan działania (propozycja)
1. Przegląd i akceptacja mapy (warsztat ~90 min lub decyzje mailowe).
2. Domknięcie zakresu: pakiet podstawowy (E1–E14) / rozszerzenia (E15–E19) / opcje.
3. User stories v3 + wycena w pakietach (godziny × stawka).
4. Realizacja i migracja treści ze starej strony (przekierowania 301).

## Otwarte decyzje (do warsztatu)
- „Co warto wiedzieć” (ok. 25 stron poza misją) — zostają / archiwum / wybrane?
- Które rozszerzenia w starcie: historie, publikacje, ośrodki, galerie, migracja 301?
- Darowizny cykliczne (PayU Recurring)?
- Strony „Dla mediów” / „Dla firm”?
- Wersja angielska (SPAGN, ECPC) — teraz / później / nie?
- Właściciel treści medycznych (recenzent).
